# Research Hub · 学术科研管理面板

一个**单文件、离线可用**的个人科研管理网页：集中管理在研论文、在投论文与已发表论文。无需安装、无需服务器、零依赖——用浏览器打开 HTML 文件即可使用。

## ✨ 功能总览

### 科研总览（Dashboard）
- 在研 / 在投 / 已发表统计与平均研究进度一览
- 进度条按阶段完成情况**实时自动计算**
- 最近更新时间线：任何论文有任何变动，时间自动刷新（精确到分钟）

### 在研论文
- **三级阶段树**：点击空心圆 ○ 标记完成（父级勾选自动级联子级），默认五级模板（引言 → 文献综述/理论假设 → 研究设计 → 实证分析 → 结论与启示）
- 阶段**自由增删改**：一级阶段自由拖动排序，二/三级阶段只能在所属父级内拖动
- **双击行内编辑**：标题、目标期刊、NEXT ACTION、文件夹路径；点空白处保存、Esc 取消
- **作者胶囊**：浅绿色圆角标签，＋ 添加、悬停右上角 ✕ 删除、左右拖动排序
- **优先级下拉**（High / Medium / Average，颜色区分）+ 关键词搜索与优先级筛选
- 一键**流转到在投**（自动继承标题、作者、文件夹路径）

### 在投论文
- 标题、作者、当前期刊、投稿日期、稿件编号、投稿次数、NEXT ACTION 全部双击可编辑
- **投稿历史**：支持增删；日期与期刊双击修改，状态为下拉选项（已投稿 / 初审中 / 外审中 / 小修改 / 大修改 / 已录用 / 已拒稿）
- 一键**流转到已发表**（当前期刊自动转为期刊名）

### 已发表论文
- 卡片预览 + **GB/T 7714-2025 引用列表**双视图（中英分栏、5 种排序、一键复制）
- **引用次数**：全部论文可双击手工修改；英文期刊论文可按 DOI 从 **Crossref** 自动获取（单篇按钮带逐级提醒，也可批量更新）
- 中英文**按期刊名称自动识别**（期刊名含中文即视为中文文章）
- **一键导出**：生成数据写死的独立静态网页——主题一致、GB/T 7714 参考文献、每条附"查看更多"展开摘要 / 关键词 / 引用次数 / DOI 链接，可直接分享或打印

### 卡片通用能力
- 三个页面均支持**新增**（固定追加到末尾，防连点）、**删除**（带确认）、**拖动排序**
- 卡片编号（R001 / S001 / P001…）在增删、拖动后**自动从小到大重新编排**
- 内部稳定键机制：重新编号不会影响任何已保存的数据

### 主题与隐私
- 6 套主题（学术蓝 / 石墨 / 森林 / 酒红 / 靛蓝 / 暖纸），自动记忆
- 所有数据存于浏览器 `localStorage`，HTML 文件本身保持干净
- Crossref 联系邮箱在**页面内输入**（仅存本地），不写死在代码里——文件可放心公开分享

## 🚀 快速开始

1. 下载 `Research-Hub-V2.1.html`
2. 用任意现代浏览器打开（Chrome / Edge / Firefox）
3. 直接在页面上编辑，浏览器会自动记住所有改动

### 导入自己的数据
示例数据位于 `<script>` 顶部的 `DATA_EMBEDDED` 对象，结构自带注释，替换为你的论文即可；也可以完全用页面上的 **＋ 新增** 按钮从零录入。

### 导出与分享
- 已发表论文页 → **⬇ 一键导出**，生成完全静态、数据写死的独立 HTML，随处可托管
- 分享前记得在页面上方填写 Crossref 邮箱，方便访客礼貌地刷新引用数据

## 🛠 技术说明

- 纯原生 HTML / CSS / JS 单文件，零依赖，可完全离线使用
- 本地存储采用带版本号的键（`research-hub-stages-v1`、`research-hub-fields-v1`、`research-hub-cards-v1`、`research-hub-crossref-*`）
- Crossref 查询在填写邮箱后自动附加 `mailto=` 礼貌参数，结果本地缓存
- 中英文识别：期刊名含 CJK 字符 → 中文文章，否则英文（期刊名为空时回退 `language` 字段）
